# ระบบสอบออนไลน์ (Online Exam App)

สถานะ: **Phase 7 เสร็จ** (เพิ่มการแสดงเฉลยรายข้อให้ผู้เรียนตามโหมดที่ Admin ตั้ง) ต่อจาก **Phase 5–6** — Admin จัดการข้อสอบ/รอบสอบ/ลิงก์/QR (Phase 3–4) + ผู้เรียนเข้าสอบได้จริง: กรอกชื่อ, ทำข้อสอบ, นาฬิกานับถอยหลังตามเวลาเซิร์ฟเวอร์,
บันทึกคำตอบอัตโนมัติ, ทำต่อหลังรีเฟรช, ส่งอัตโนมัติเมื่อหมดเวลา, หน้าสรุปคะแนนของตนเอง
ยังไม่มี: ตารางผลสอบ/รายละเอียดรายคน/ปุ่มอนุญาตสอบใหม่/ส่งออกของ Admin (Phase 8)

## ทดสอบความถูกต้องในเครื่องผม (ผ่านแล้ว)
- `npm test` → 18 รายการ (เพิ่มกติกาแสดงเฉลย + ตัวสร้างหน้าเฉลย): validation, การแปลงเวลาไทย↔UTC, ฟอร์มรอบสอบ, ตรรกะนาฬิกา/ลำดับการบันทึก/การรวมคำตอบของหน้าสอบ (Node 22+ รัน .ts ได้เลย ไม่ต้องติดตั้งแพ็กเกจ)
- โค้ดหน้าเว็บ **ยังไม่เคย build/รันจริง** (เครื่องผมติดตั้งแพ็กเกจไม่ได้) ต้องให้คุณ deploy แล้วลองตามด้านล่าง

## ตั้งค่า Supabase (ถ้าทำ Phase 1–2 แล้ว ข้ามข้อ 1)
1. รัน migration 0001–0003 (ดูรายละเอียดในรอบก่อน)
2. **ปิดการสมัครเอง**: Dashboard → Authentication → Sign In / Providers → ปิด “Allow new users to sign up”
3. เก็บค่า 3 ตัวจาก Project Settings → API: Project URL, anon key, service_role key (**ห้ามเปิดเผย service_role**)

## สร้างผู้ดูแลคนแรก (เลือกวิธีใดวิธีหนึ่ง)
**วิธี ก — ไม่ต้องติดตั้งอะไรในเครื่อง**
1. Dashboard → Authentication → Users → Add user → Create new user → ใส่อีเมล + รหัสผ่าน (≥10 ตัว) และติ๊ก Auto Confirm User
2. คัดลอก User UID ของผู้ใช้นั้น แล้วรันใน SQL Editor:
```sql
insert into public.admin_profiles (id, display_name)
values ('วาง-UID-ตรงนี้', 'ชื่อที่ต้องการแสดง');
```
**วิธี ข — มี Node.js**: `npm run create-admin -- you@example.com 'รหัสผ่าน' 'ชื่อ'` (ต้องมี .env.local)

## Deploy ขึ้น Vercel (ไม่ต้องรันในเครื่อง)
1. สร้าง repository บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์ `exam-app` ทั้งหมด (อย่าอัปโหลดไฟล์ `.env.local`)
2. vercel.com → Add New → Project → เลือก repo → Framework: Next.js (ตรวจพบเอง)
3. ก่อนกด Deploy ใส่ Environment Variables:

| ชื่อ | ค่า |
|---|---|
| `SUPABASE_URL` | Project URL |
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL (ค่าเดียวกัน) |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon key |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role key |
| `NEXT_PUBLIC_APP_URL` | `https://ชื่อโปรเจกต์.vercel.app` (ใส่หลัง deploy ครั้งแรกแล้ว redeploy ก็ได้) |
| `CRON_SECRET` | ข้อความสุ่มยาว ๆ |

4. Deploy → เปิด `https://ชื่อโปรเจกต์.vercel.app/admin` → ล็อกอินด้วยบัญชีที่สร้างไว้

## เช็กลิสต์ทดสอบ Phase 3 (ทำตามแล้วแจ้งผลได้เลย)
- [ ] ล็อกอินด้วยรหัสผิด → ขึ้นข้อความผิดพลาด ; รหัสถูก → เข้าหน้าหลัก
- [ ] เปิด `/admin/sets` ตอนยังไม่ล็อกอิน (หน้าต่างไม่ระบุตัวตน) → เด้งไปหน้าล็อกอิน

- [ ] แก้ชุดข้อสอบต้นฉบับ (เปลี่ยนคำถาม) → เปิดลิงก์/ตัวอย่างรอบสอบยังเป็นข้อมูลเดิม (หน้าชุดข้อสอบมีข้อความเตือนว่ามีกี่รอบใช้ชุดนี้)
- [ ] เปิดลิงก์ในหน้าต่างไม่ระบุตัวตน / สแกน QR ด้วยมือถือ → เห็นชื่อชุดข้อสอบ จำนวนข้อ เวลา และข้อความ “ลิงก์ถูกต้อง” (ยังเริ่มสอบไม่ได้ จะทำใน Phase 5)
- [ ] ตรวจว่าที่อยู่ในลิงก์เป็นโดเมนจริงของเว็บ (ไม่ใช่ placeholder)
- [ ] “ปิดรับผู้เข้าสอบ” → หน้าลิงก์ขึ้น “ปิดรับผู้เข้าสอบแล้ว” ; “เปิดรับอีกครั้ง” → กลับมาเปิด
- [ ] “สิ้นสุดรอบสอบ” → มีหน้าต่างยืนยัน → สถานะ “สิ้นสุดการสอบ” ไม่มี QR และลิงก์ขึ้นว่าปิดแล้ว

# Phase 5–6 — หน้าผู้เรียน + นับเวลา + บันทึกอัตโนมัติ + ส่งอัตโนมัติ

## เช็กลิสต์ทดสอบ (ใช้รอบสอบที่ตั้งเวลา 3 นาที และชุดข้อสอบสั้น ๆ 5 ข้อ ที่เฉลยไม่ซ้ำกันหมด)
ใช้ Chrome ปกติ + หน้าต่างไม่ระบุตัวตน + มือถือ เป็น “ผู้เรียนคนละคน”

**เริ่มสอบ**
- [ ] เปิดลิงก์ → เห็นชื่อชุด/คำชี้แจง/จำนวนข้อ/เวลา/คะแนนเต็ม + ช่องชื่อ นามสกุล รหัส
- [ ] กดเริ่มโดยไม่กรอกชื่อ → ไม่ผ่าน/ขึ้นข้อความเตือน
- [ ] กรอกชื่อ-นามสกุล → เข้าหน้าทำข้อสอบ นาฬิกาเริ่มที่ ~03:00 และเดินลง
- [ ] หน้าผู้ดูแล “รอบสอบ” → ตัวนับ “เข้าระบบ/กำลังสอบ” เพิ่ม และสถานะรอบเป็น “กำลังสอบ”

**ทำข้อสอบและบันทึกอัตโนมัติ**
- [ ] เลือกคำตอบ → ข้อความ “กำลังบันทึก…” แล้ว “บันทึกแล้ว ✓” ; เปลี่ยนคำตอบได้ ; แถบความคืบหน้าและตัวเลขข้อเปลี่ยนสี
- [ ] กดเลขข้อเพื่อข้ามไปข้อใดก็ได้ ; ข้อก่อนหน้า/ถัดไปทำงาน
- [ ] **รีเฟรชหน้า** (F5) → กลับมาที่หน้าสอบ คำตอบที่เลือกยังอยู่ และเวลาไม่ถูกรีเซ็ต
- [ ] ปิดแท็บแล้วเปิดลิงก์เดิมในเบราว์เซอร์เดิม → ทำต่อได้ (ไม่ถามชื่อใหม่)
- [ ] เปิดลิงก์เดียวกันใน **เบราว์เซอร์/หน้าต่างอื่น** แล้วกรอกชื่อเดิม → ถูกปฏิเสธ (“ชื่อนี้เข้าสอบรอบนี้ไปแล้ว”) และเวลาของคนเดิมไม่ถูกรีเซ็ต
- [ ] เปิด DevTools → Network → Offline แล้วเลือกคำตอบ 2 ข้อ → ขึ้น “ไม่มีอินเทอร์เน็ต…” ; เวลายังเดิน ; กลับ Online → ขึ้น “บันทึกแล้ว ✓” ; รีเฟรชแล้วคำตอบ 2 ข้อนั้นอยู่
- [ ] เหลือเวลา < 5 นาที / < 1 นาที → นาฬิกาเปลี่ยนสีและมีข้อความเตือน (ตั้งรอบสอบ 3 นาทีจะเห็นทันที)

**ส่งข้อสอบ**
- [ ] กด “ส่งข้อสอบ” ขณะยังตอบไม่ครบ → หน้าต่างบอกจำนวน/เลขข้อที่ยังไม่ได้ตอบ ; “กลับไปตอบ” ปิดหน้าต่างได้
- [ ] ยืนยันส่ง → หน้าสรุปผล: คะแนน เต็ม % ถูก/ผิด/ไม่ได้ตอบ เวลาที่ใช้ ผ่าน/ไม่ผ่าน (ถ้าตั้งเกณฑ์) — **ตรวจเลขด้วยมือว่าตรงกับที่ตอบไว้**
- [ ] เปิดลิงก์เดิมอีก/กด Back → เห็นหน้าสรุปผลเดิม ไม่เริ่มสอบใหม่และแก้คำตอบไม่ได้
- [ ] ตั้งคะแนนรายข้อไม่เท่ากัน (เช่น 1/2/3) แล้วตอบถูกบางข้อ → คะแนนถูกตามน้ำหนัก

**หมดเวลา / Admin ปิดรอบ**
- [ ] เลือกคำตอบ 2 ข้อแล้วปล่อยให้เวลาหมด (เปิดหน้าสอบค้างไว้) → ระบบส่งให้เอง ไปหน้าสรุปผล เขียนว่า “หมดเวลา…” และคะแนนคิดจาก 2 ข้อนั้น
- [ ] เริ่มสอบอีกคน เลือก 1 ข้อ แล้ว **ปิดแท็บ** ปล่อยจนหมดเวลา → รอ ~1–2 นาที เปิดลิงก์เดิม → เป็นหน้าสรุปผลแบบ “หมดเวลา” (pg_cron/ตรวจแบบ lazy ส่งให้)
- [ ] ผู้เรียนกำลังสอบอยู่ → Admin กด “สิ้นสุดรอบสอบ” → หน้าผู้เรียนพาไปหน้าสรุปผลเองภายในไม่กี่วินาที (ตอนเลือกคำตอบถัดไป/ครบ 60 วินาที/สลับแท็บกลับมา) ติดสถานะ “ผู้ดูแลปิดรอบสอบ”
- [ ] หลังรอบสอบปิด เปิดลิงก์ในเบราว์เซอร์ใหม่ → “ปิดรับผู้เข้าสอบแล้ว”

**หลายคนพร้อมกัน / มือถือ**
- [ ] ผู้เรียน 3–5 คน (หรือ 3 เบราว์เซอร์) สอบพร้อมกัน แต่ละคนเห็นเฉพาะผลของตนเอง
- [ ] บนมือถือจริง: ปุ่มตัวเลือกกดง่าย นาฬิกาเห็นชัด ไม่ต้องซูม ; ล็อกจอแล้วปลดกลับมา เวลาถูกต้อง

## ล้างข้อมูลทดสอบเพื่อใช้ชื่อเดิมซ้ำ (SQL Editor)
```sql
-- ทำให้ผู้เข้าสอบทุกคนของรอบนี้ “ถูกยกเลิก” เพื่อให้ใช้ชื่อเดิมสอบใหม่ได้ (ข้อมูลยังอยู่เพื่อตรวจสอบ)
update public.exam_participants set voided_at = now()
where session_id = 'ใส่-id-ของรอบสอบ' and voided_at is null;
```
(หรือสร้างรอบสอบใหม่จากชุดเดิม ซึ่งง่ายกว่า) — ปุ่ม “อนุญาตสอบใหม่” สำหรับ Admin จะมีใน Phase 8

# Phase 7 — แสดงเฉลยรายข้อให้ผู้เรียน
ไม่มี migration ใหม่ ไม่มีแพ็กเกจใหม่ ไม่มี Environment Variable ใหม่

**ไฟล์ที่แก้:** `lib/exam-logic.ts`, `app/e/[code]/result/page.tsx`, `app/globals.css`, `tests/exam-logic.test.ts`, `README.md`, `docs/ARCHITECTURE.md`
(ลากทับ `app`, `lib`, `tests`, `docs`, `README.md` ได้เลย)

## กติกา (ตั้งที่ “การแสดงเฉลยหลังสอบ” ของรอบสอบ)
| โหมด | ผู้เรียนเห็นเฉลยเมื่อ |
|---|---|
| แสดงทันทีหลังส่งข้อสอบ | ส่งข้อสอบแล้ว |
| แสดงหลังสิ้นสุดรอบสอบ | Admin กด “สิ้นสุดรอบสอบ” หรือ “ปิดใช้งาน” แล้ว |
| ไม่แสดงเฉลย | ไม่เห็น (Admin เปลี่ยนโหมดทีหลังได้ มีผลทันทีทุกหน้า) |

ผู้เรียนเห็นเฉพาะข้อสอบของตนเอง: คำถาม, ตัวเลือก ก ข ค ง, คำตอบที่ตนเลือก, เฉลย, ถูก/ผิด/ไม่ได้ตอบ, คำอธิบาย (ถ้ามี) — ตอบผิดจะเห็นทั้ง “คำตอบของคุณ” และ “เฉลย” (ใช้ข้อความกำกับ ไม่พึ่งสีอย่างเดียว)

## เช็กลิสต์ทดสอบ (ใช้รอบสอบ 3 นาที คนที่ 1 ตอบถูกหมด คนที่ 2 ตอบผิด 1 ข้อ ไม่ตอบ 1 ข้อ)
**โหมด “แสดงทันที”**
- [ ] ส่งข้อสอบ → หน้าผลมีส่วน “เฉลยรายข้อ” ครบทุกข้อ
- [ ] ข้อที่ตอบถูก: ป้าย “ตอบถูก” ขอบเขียว ; ข้อที่ตอบผิด: เห็น “คำตอบของคุณ” (แดง) และ “เฉลย” (เขียว) ในข้อเดียวกัน ; ข้อที่ไม่ตอบ: ป้าย “ไม่ได้ตอบ” + ข้อความบอกว่าเฉลยคือข้อไหน
- [ ] คำอธิบายเฉลยของข้อที่ใส่ไว้แสดงถูกข้อ ; ข้อที่ไม่ได้ใส่ไม่มีกล่องว่าง
- [ ] จำนวนถูก/ผิด/ไม่ได้ตอบ ในรายข้อ ตรงกับตัวเลขสรุปด้านบน

**โหมด “หลังสิ้นสุดรอบสอบ”** (Admin เปลี่ยนที่หน้ารอบสอบ → บันทึก)
- [ ] รีเฟรชหน้าผลตอนรอบยังเปิดอยู่ → ขึ้นข้อความ “เฉลยรายข้อจะแสดงเมื่อสิ้นสุดรอบสอบ” และ **ไม่มีเฉลยในหน้า**
- [ ] Admin กด “สิ้นสุดรอบสอบ” → รีเฟรชหน้าผลของผู้เรียน → เฉลยปรากฏ

**โหมด “ไม่แสดงเฉลย”**
- [ ] หน้าผลขึ้น “ผู้ดูแลยังไม่เปิดให้ดูเฉลย” ; สลับกลับเป็น “แสดงทันที” → รีเฟรช → เฉลยปรากฏ (ไม่ต้องสอบใหม่)

**ความปลอดภัย (สำคัญ)**

- [ ] ระหว่างทำข้อสอบ (หน้า /take) ค้นหาคำว่า `is_correct` และคำอธิบายเฉลยใน View source → **ต้องไม่พบ**
