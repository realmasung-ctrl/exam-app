# UI/UX (Phase 2) — ภาษาไทย, Mobile-first

## Design tokens
- ฟอนต์: Noto Sans Thai (fallback: system-ui, sans-serif); ขนาดพื้นฐาน 16px, คำถาม 18–20px
- สี: primary `#2457D6`, success `#1E8E4E`, warning `#B7791F`, danger `#C53030`, พื้น `#F7F8FA`, ข้อความ `#1A202C`
- ปุ่มตัวเลือกสูงอย่างน้อย 56px เต็มความกว้าง (แตะง่ายด้วยนิ้วโป้ง) ; คอนทราสต์ตัวอักษรผ่าน WCAG AA
- รองรับ dark mode ภายหลัง (ไม่อยู่ในเฟสแรก)

## หน้าผู้เรียน (4 หน้า, ไม่มีเมนูรบกวน)
1. **/e/[code] — เข้าร่วม** : ชื่อรอบสอบ, คำชี้แจง, จำนวนข้อ, เวลา, คะแนนเต็ม, ช่อง ชื่อ/นามสกุล (+รหัสถ้ารอบบังคับ), ปุ่ม "เริ่มทำข้อสอบ"
2. **/e/[code]/take — ทำข้อสอบ**
```
┌───────────────────────────────┐
│ ชื่อชุดข้อสอบ        ⏱ 12:34  │  ← แถบบนติดหน้าจอ; ≤5 นาทีเป็นสีเหลือง, ≤1 นาทีสีแดง+ข้อความเตือน
│ สมชาย ใจดี    ตอบแล้ว 7/10    │
│ ▓▓▓▓▓▓▓░░░                    │  ← progress
├───────────────────────────────┤
│ ข้อ 3 / 10                    │
│ คำถาม ........................ │
│ [ ก. ................ ]        │
│ [ ข. ................ ]  ← เลือกแล้วเน้นสี │
│ [ ค. ................ ]        │
│ [ ง. ................ ]        │
│ สถานะ: ✓ บันทึกแล้ว           │  ← กำลังบันทึก… / บันทึกไม่สำเร็จ (ลองใหม่)
├───────────────────────────────┤
│ [← ก่อนหน้า]  [ถัดไป →]       │
│ (1)(2)(3)(4)… ปุ่มเลขข้อ ● ตอบแล้ว ○ ยังไม่ตอบ │
│ [ ส่งข้อสอบ ]                 │
└───────────────────────────────┘
```
   - Modal ยืนยันก่อนส่ง: "ยังไม่ได้ตอบ N ข้อ — กลับไปตอบ / ยืนยันส่ง"
   - ออฟไลน์: แถบแจ้ง "ขาดการเชื่อมต่อ — นาฬิกายังเดินตามเวลาเซิร์ฟเวอร์" ; เมื่อกลับมาซิงก์เวลา+คำตอบทันที
3. **/e/[code]/result — สรุปผล** : คะแนน/คะแนนเต็ม, %, เวลาที่ใช้ (นาที:วินาที), ถูก/ผิด/ไม่ตอบ, ผ่าน/ไม่ผ่าน ; ถ้าอนุญาต แสดงรายข้อ (คำตอบของฉัน vs เฉลย + คำอธิบาย) มิฉะนั้นแสดงข้อความ "ผู้ดูแลยังไม่เปิดเผยเฉลย"

## หน้า Admin (เมนูข้าง / แท็บล่างบนมือถือ)
หน้าหลัก · จัดการชุดข้อสอบ · สร้างข้อสอบ · จัดการรอบสอบ · ลิงก์และ QR · ผลสอบ · ตั้งค่าระบบ (เชิญ Admin, สำรองข้อมูล)

- **ตัวแก้ไขชุดข้อสอบ**: รายการคำถามด้านซ้าย (ลากสลับลำดับ / ปุ่มขึ้น-ลง), ฟอร์มแก้ไขด้านขวา (คำถาม, ก-ง, เลือกเฉลยด้วย radio, คะแนน, คำอธิบายเฉลย), แถบตรวจความครบถ้วนแสดงข้อที่ยังไม่สมบูรณ์, ปุ่ม "ดูตัวอย่าง" (เปิดหน้าผู้เรียนแบบไม่บันทึกผล)
- **รอบสอบ**: ฟอร์ม (ชื่อรอบ, ชุดข้อสอบ, เวลา, เปิด/ปิดรับ, เกณฑ์ผ่าน, โหมดเฉลย, บังคับรหัสประจำตัว, จำนวนผู้เข้าสอบที่คาดไว้) → "เปิดรอบสอบ" → การ์ดลิงก์ + QR (คัดลอก/ดาวน์โหลด PNG) + ปุ่ม "ปิดรับผู้เข้าสอบ" / "สิ้นสุดรอบสอบ" (มี modal ยืนยันบอกจำนวนคนที่กำลังสอบ)
- **ผลสอบ**: การ์ดสรุป (คาดไว้ / เข้าระบบ / กำลังสอบ / ส่งแล้ว / ยังไม่เริ่ม) + ตาราง ค้นหา เรียง กรอง ; คลิกชื่อ → รายละเอียดรายข้อ (คำตอบที่เลือกคู่เฉลย สีเขียว/แดง) ; ผู้ที่ยังสอบอยู่แสดง "ยังไม่ส่ง" ไม่แสดงคะแนน ; ปุ่มส่งออก CSV/Excel ; รีเฟรชอัตโนมัติทุก ~5 วินาที
